# topo-llvm runtime C-ABI compatibility

The `topo-llvm` runtime ships seven C-ABI shared libraries that
optimization passes inject calls into. Each library has an **independent
ABI version macro** in its public header and a corresponding
`topo_<lib>_version()` introspection symbol. Mismatched
header-vs-library versions are a hard error, not silent UB.

This document records the bump history and the rule that triggers a
bump.

## Why per-library versions (not one global)

Each runtime is built, linked, and loaded independently. A consumer
that does not enable `[adaptive]` never links `libtopo-adaptive`; its
binary's compatibility against `libtopo-parallel` is unrelated to
adaptive's version. Folding everything under one `TOPO_RT_VERSION`
forces every reader to think about runtimes they do not depend on
(and forces a bump on parallel any time observability changes a
field). Per-library versions keep the blast radius of a change
proportional to the change.

## The single bump rule

**Bump iff** any signature already declared in this header changes
(parameter added / removed / retyped, return type retyped, calling
convention changed, or — for NDJSON / wire payloads — the existing
record schema becomes non-backward-compatible).

**Do not bump** when adding a new entry point that older consumers
cannot reference, OR when adding an OPTIONAL field that older
consumers ignore (this is the same rule
`topo_pass_event_emit_sized()` was introduced under).

When in doubt, bump — the cost of a false-positive bump is one CI
run; the cost of a missed bump is a runtime crash in production.

## How a pass should check the version

Recommended pattern — inject a one-time ctor at link time (or at the
top of the first generated call site) that calls the runtime
introspection symbol and aborts on mismatch:

```c
// Generated by TopoParallelPass once per module.
__attribute__((constructor))
static void __topo_check_parallel_abi(void) {
    if (topo_parallel_version() != TOPO_PARALLEL_ABI_VERSION) {
        fprintf(stderr,
                "topo-runtime ABI mismatch: libtopo-parallel reports "
                "v%u but caller expects v%u — rebuild against "
                "matching runtime\n",
                topo_parallel_version(), TOPO_PARALLEL_ABI_VERSION);
        abort();
    }
}
```

`jit_engine_rt.h` already does this from `topo_jit_api.cpp:209-215`;
the same shape applies to the other six libraries.

## Bump procedure

1. Edit the header: bump the `_ABI_VERSION` macro by 1, update the
   trailing `vN: …` comment with the change description.
2. Update this file: bump the "Current" column in the matrix; add a
   line under the matrix recording the change rationale and date.
3. Pass-side: update the pass that injects the version check so the
   compile-time constant matches.
4. Add or update a runtime test that constructs the new entry point
   surface and asserts both the introspection symbol and the macro
   agree.
